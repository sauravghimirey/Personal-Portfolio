Saurav Ghimire | Personal Portfolio

A modern, responsive, and interactive personal portfolio website built with HTML, CSS, and Vanilla JavaScript to showcase my technical skills, projects, education, certifications, and professional interests.

Live Portfolio
🌐 https://sauravghimire1.com.np
Overview

This portfolio highlights my technical background, development journey, and continuous learning through a clean, interactive, and user-friendly interface.

Built with a modular JavaScript architecture and centralized content management, the website is designed for easy customization, scalability, and maintainability.

Features
Responsive Design – Optimized for desktop, tablet, and mobile devices.
Dynamic Content Management – Centralized configuration for personal information, education, projects, and skills.
Interactive Navigation – Smooth navigation across portfolio sections.
Theme Switching – Light and dark mode functionality.
Animated Loading Screen – Custom loading animation with progress indicators.
Project Showcase – Dedicated section highlighting development projects.
Certificate Gallery – Organized display of certifications and achievements.
Beyond Gallery – Showcases personal interests, experiences, and activities.
Contact Form – Integrated interface for professional communication.
Visual Effects – Interactive animations and UI enhancements.
Tech Stack
HTML5 – Website structure and content.
CSS3 – Styling, layouts, animations, and responsive design.
JavaScript (Vanilla) – Interactive functionality and dynamic content management.
WebP & SVG – Optimized images and scalable icons.
Git & GitHub – Version control and project management.
