## Overview

This portfolio highlights my technical background, development journey, and continuous learning through a clean, interactive, and user-friendly interface.

It uses a modular JavaScript architecture and centralized content management, so it is easy to customize, scale, and maintain.

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices.
- **Dynamic Content Management**: Centralized configuration for personal information, education, projects, and skills.
- **Interactive Navigation**: Smooth navigation across portfolio sections.
- **Theme Switching**: Light and dark mode.
- **Animated Loading Screen**: Custom loader with progress indicators.
- **Project Showcase**: Dedicated section highlighting development projects.
- **Certificate Gallery**: Swipeable display of certifications and achievements.
- **Beyond Gallery**: Showcases personal interests, experiences, and activities.
- **Contact Form**: Integrated form for professional communication.
- **Visual Effects**: Interactive animations and UI enhancements.

## Tech Stack

| Technology | Description |
|---|---|
| **HTML5** | Website structure and content |
| **CSS3** | Styling, layouts, animations, and responsive design |
| **JavaScript (Vanilla)** | Interactivity and dynamic content rendering |
| **WebP & SVG** | Optimized images and scalable icons |
| **Git & GitHub** | Version control and project management |

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/sauravghimirey/Personal-Portfolio.git
```

### 2. Go to the project folder

```bash
cd Personal-Portfolio
```

### 3. Run locally

Open `index.html` in your browser. No extra dependencies, frameworks, or build tools are needed.
